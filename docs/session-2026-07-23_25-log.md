# Steel Battalion campaign — what this work established (2026-07-23 → 07-25)

A navigable index of everything learned across the multi-day push, with
pointers to the authoritative doc for each. Chronological within threads.

## 1. Steel Battalion: from "Intro" to combat-verified (branch `steel-battalion`)

**Result:** original Steel Battalion goes intro → menus → character signup →
cutscene → cockpit → startup ritual → gear → **driving + full combat loop
(move/aim/fire/lock-on/magazine)** — believed a first for the original game on
any xemu build via the emulated controller. Fully closed: **ISS-B11**.

Root causes and fixes (all ported/landed):
- **Crash (`assert levels>0`, texture.c:294, xemu#1238):** NOT a decode bug and
  NOT clampable — real NV2A faults on `MIPMAP_LEVELS==0`; the `0xFF000000` word
  was uninitialized guest memory read as a texture because a GPU surface wasn't
  synced before a guest DMA (async NtReadFile race). Fixed by porting upstream
  **PR #2514** (DMA via mem callbacks). Plus a log-and-survive diagnostic
  replacing the assert.
- **Dead menu input:** the game polls only the SBC XID (`bType 0x80`) and
  ignores gamepad XIDs. Fixed by porting **PR #1803** (SBC device, keyboard
  placeholder). Input + crash fix had to land together.
- **"Can't move" (field incident):** NOT a bug — the mech idled in Reverse
  (from N, one LCtrl = R; two LShifts back to 1st). The stock gear encoding
  (254=R/255=N/1-5) is correct; a "fix" I wrote was falsified by the user's
  live play and reverted. Detail: KNOWN_ISSUES ISS-B11.
- **Hotkey collisions (ISS-B12):** the SBC keyboard map claims F5-F12, fighting
  xemu globals + our F8/F9 VR keys. Fixed: `xemu_input_keyboard_feeds_sbc()`
  gates all global/VR F-key hotkeys when a keyboard-fed SBC is bound ("cockpit
  wins"). Also rebound the cockpit keys off the F-row in the launch config
  (config-only, no rebuild).
- **ISS-B14 (RETRACTED):** an in-game "freeze" I diagnosed and killed was a
  live session misread from remote evidence (stale xwd capture + single-sample
  D-state). Recorded as a discipline lesson: remote evidence never overrides
  the person at the screen; "is it frozen?" is a question, not a kill order.

Startup ritual (rebound layout): `H` hatch → `F O U B V` toggles → `I`
ignition → `LShift` gear → `W` pedal. Gear glyph shows R/N/1-5 (amber R).

## 4. Quest 3 passthrough (framework `docs/14-passthrough-spec.md`)

Verified viable on our exact stack: WiVRn ≥26.6 advertises
`XR_ENVIRONMENT_BLEND_MODE_ALPHA_BLEND`; the app just ends frames with it and
the Quest renders the real desk client-side via `XR_FB_passthrough`, our quads
composited on top. No permission, no client toggle. Capability-AND-request
gated → non-passthrough setups render byte-identically. Upgrade rig+client to
≥26.6.2 (NVENC alpha fix) before relying on it. Specced, not built.

## 5. Performance research (branch `sb-graphics-research`)

The deep result — see **`docs/sb-graphics-findings.md`** for the full
authoritative write-up. Final state (2026-07-26, "locked in"):
- **SHIPPED, always-on: the read fast path** (quiesced mem-access
  callbacks skip READ dispatch at the physmem walk). Trapped surface
  reads ~23,000 → 1-2/frame measured; removes the 2-5 ms trap tax + the
  vCPU↔pfifo pgraph.lock contention; scales with combat. Zero VK errors.
- **Built + retained, default OFF: the narrow-fence ring** (per-slot
  command buffers/semaphores/fences, submit/finish split, delta-synced
  staging, identity-narrow waits, `/tmp/narrowfence-on` live toggle).
  Async early-submit measured honestly negative twice (~4-7 ms worse):
  ~8 serialization walls/frame and the untouched STALLED occlusion-query
  polls (2-4/frame, targeting reticle) re-drain everything — narrowing
  k of n walls pays nothing until the last wall falls. Architecture is
  the prerequisite for the scoped next step, **async query readback** —
  since attempted (XEMU_ASYNC_QUERIES): it absorbed the query walls but
  introduced light flicker and is now hard-OFF; redesign = the deferred-epoch
  ring (ISS-B16).
- Cost model: floor = surface-sync drains (scale-independent), slope =
  texture re-hash volume (4.5 → 35+ MB/frame); reader = the 128×128
  radar-sweep buffer (seen via XEMU_SURF_DUMP).
- Full env-gated instrumentation kit (counters + access logger +
  surface-dump + per-surface attribution + self-logging H6 summary +
  interleaved-ABABA A/B harness `~/ab-interleaved.sh`).
- Blocker (documented): SBC save states won't `-loadvm`.
- Portable to `steel-battalion`: the read fast path is semantically
  independent of the ring (cherry-pick 0f76167240; expect textual
  conflicts, trivial to resolve).
